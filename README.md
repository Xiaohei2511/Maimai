# 麦麦 · 爱宠成长日记

基于 uni-app / Vue 3 的宠物成长时间线。面向微信小程序与 iOS/Android App，共用前端代码和同一套同步 API。

## 功能

- 「我的宠物」：多只宠物资料，生日、品种，以及疫苗与驱虫入口
- 「成长时间线」：按日期排列、按宠物筛选；一条动态支持最多 9 张照片或 1 段视频，文字可选
- 「动态详情」：媒体、出镜宠物、点赞和评论
- 「宠友圈」：登录后可将动态公开分享给其他用户，互相点赞和评论
- 本机离线保存；配置服务端后可用邮箱账号在小程序和 App 之间同步

首次打开会显示麦麦和米粒两只示例宠物及几条示例动态，可编辑资料并添加自己的记录。

## 本地运行

要求 Node.js 22 以上。执行 `npm install`，然后：

```sh
npm run dev:h5
npm run build:mp-weixin
npm run build:app
npm run server
```

微信开发者工具导入 `dist/build/mp-weixin`。App 构建产物位于 `dist/build/app`，需在 HBuilderX 中配置正式 AppID、签名和图标后打包。`src/manifest.json` 中的微信 AppID 也需替换为自己的。

## 开启跨端同步

1. 将 `server/` 运行在有持久化磁盘的服务器，配置 HTTPS 反向代理。SQLite 数据和上传媒体保存在 `server/data/`，应定期备份。
2. 设置 `PUBLIC_BASE_URL=https://你的域名`，保证上传媒体生成可访问的 HTTPS 地址。
3. 复制 `.env.example` 为 `.env`，将 `VITE_API_BASE_URL` 改成这个 HTTPS 域名，再重新构建客户端。
4. 在微信小程序后台把该域名加入 `request` 和 `uploadFile` 合法域名。App 发布时也应使用 HTTPS。
5. 两端使用同一邮箱和密码登录。首次登录会把当前本机记录上传；以后发布动态、编辑宠物或健康记录时同步。

目前同步采用整份日记覆盖写入。两台设备同时离线修改并随后同步时，后一次上传会覆盖前一次；正式上线前应改为逐条记录同步和冲突处理。上传媒体使用随机但公开可访问的链接，正式处理私密相册前还需要授权访问或签名链接。公开动态会显示给所有已登录用户；请在发布时自行选择是否分享。未分享的动态只保存在个人相册。
